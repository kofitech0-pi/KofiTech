# KofiTech

Landing page institucional desenvolvida pela equipe KofiTech para apresentação do Projeto Integrador.

O website foi criado com o objetivo de reunir informações sobre a equipe, projeto desenvolvido, competências, tecnologias utilizadas e formas de contato, funcionando como um portfólio digital acadêmico.

---

## ✨ Funcionalidades

- Apresentação da equipe
- Seção sobre a KofiTech
- Exibição do projeto desenvolvido
- Sessão de integrantes
- Informações de contato
- Layout responsivo
- Navegação moderna e intuitiva

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## ▶️ Como executar

### Clone o repositório

```bash
git clone https://github.com/kofitech0-pi/KofiTech.git
```

### Entre na pasta

```bash
cd KofiTech
```

### Execute

Abra o arquivo:

```bash
index.html
```

ou utilize a extensão Live Server do VS Code.
